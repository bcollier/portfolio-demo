# Portfolio Demo

A small, deliberately simple portfolio website made as an example for the optional **Portfolio Website** assignment in 70-445 Artificial Intelligence for Business Leaders (Carnegie Mellon, Tepper School of Business, Fall 2026).

**Live site:** https://bcollier.github.io/portfolio-demo/

## What's in here

| File | What it does |
|---|---|
| `index.html` | All the content: nav bar, intro, About, Projects, Contact |
| `style.css` | Colors, fonts, layout, and the phone-friendly version |
| `script.js` | Two small features: a dark mode button and cards that fade in as you scroll |
| `images/` | One picture per project card |
| `PROMPTS.md` | The prompt log: what was asked of the AI assistant to build this |

No frameworks, no build step, no installs. GitHub Pages serves these files exactly as they are.

## Make your own

1. Click **Use this template** (or **Fork**) at the top of this page, or start a new empty repository.
2. Replace the text in `index.html` with your own projects and swap the pictures in `images/`.
3. Go to **Settings > Pages**, set the source to the `main` branch and `/ (root)` folder, and save.
4. Wait a minute or two, then visit `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`.

Or skip all of that and ask an AI coding assistant to build one for you from scratch. The starter prompt in the assignment is a good place to begin.
